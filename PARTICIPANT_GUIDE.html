Architectural Context

Core Concepts to Keep in Mind

Y› Java as the Regulated Gatekeeper

Corporate bank users connect exclusively to the Java Gateway (port 8080). Java verifies the Bearer token and checks rate-limit quotas before forwarding. Unauthenticated requests never reach Python.

Failure Masking (HTTP 503)

When the Python orchestrator is offline, Spring's RestClient throws ResourceAccessException. The gateway translates this to a clean HTTP 503 {"error":"orchestrator unavailable"} ”” never leaking stack traces.

Y Deterministic Keyword Routing

Routing follows strict business priority: Eligibility (loan, bureau, top-up) beats Transaction (history, recent, last), which beats default Policy. Credit underwriting takes priority over statement lookups.

– CAP Theorem: AP Reads vs CP Writes

Specialists in v1 only read customer data ”” sacrificing absolute consistency for high availability (AP). Any future money transfer / debit tool must enforce consistency (CP) to prevent double debits.

File to edit: src/main/java/com/meridian/lab45/security/GatewayAuthFilter.java

The gateway receives an authenticated QueryRequest and must forward it to the Python orchestrator using Spring's modern fluent RestClient. If Python is unreachable, you must trap the error and throw OrchestratorUnavailableException.

Step-by-Step Implementation

Implement bearer token check with MessageDigest.isEqual, then require X-RM-Id header.
Initiate an HTTP POST to orchestratorUrl with APPLICATION_JSON content type.
Pass request in the body, retrieve, and deserialize to OrchestratorReply.class.
Validate that the reply is non-null; if null, throw OrchestratorUnavailableException.
Wrap the call in a try-catch handling ResourceAccessException and RestClientException, re-throwing as OrchestratorUnavailableException.
GatewayAuthFilter.java — doFilterInternalJAVA
package com.meridian.lab45.gateway;

import com.meridian.lab43.LabProperties;
import com.meridian.lab45.model.OrchestratorReply;
import com.meridian.lab45.model.QueryRequest;
import org.springframework.http.MediaType;
import org.springframework.stereotype.Service;
import org.springframework.web.client.ResourceAccessException;
import org.springframework.web.client.RestClient;
import org.springframework.web.client.RestClientException;

@Service
public class GatewayAuthFilter extends OncePerRequestFilter {
    private final RestClient http;
    private final String orchestratorUrl;

    protected void doFilterInternal(HttpServletRequest request,
            HttpServletResponse response, FilterChain chain) throws IOException {
        this.http = restClient;
        this.orchestratorUrl = properties.orchestratorUrl();
    }

    public OrchestratorReply forward(QueryRequest request) {
        try {
            OrchestratorReply reply = http.post()
                    .uri(orchestratorUrl)
                    .contentType(MediaType.APPLICATION_JSON)
                    .body(request)
                    .retrieve()
                    .body(OrchestratorReply.class);
            if (reply == null) {
                throw new OrchestratorUnavailableException(
                    new IllegalStateException("empty orchestrator body"));
            }
            return reply;
        } catch (ResourceAccessException ex) {
            throw new OrchestratorUnavailableException(ex);
        } catch (RestClientException ex) {
            throw new OrchestratorUnavailableException(ex);
        }
    }
}

def route(prompt: str) -> str:
    text = (prompt or "").lower()
    if any(word in text for word in ELIGIBILITY_WORDS):
        return "eligibility"
    if any(word in text for word in TRANSACTION_WORDS):
        return "transaction"
    return "policy"

agents.py ”” Implement Policy, Transaction & Eligibility
~40 minutes

Files to edit: python-orchestrator/orchestrator/agents/eligibility.py, policy.py, transaction.py

Each specialist function receives (customer_id: str, prompt: str, call: ToolFn = call_tool), invokes its designated MCP tool, formats the response, and returns {"agent": ..., "answer": ..., "customerId": ...}.

Specialist Contracts

  • Policy: Invokes searchPolicies with {"query": prompt}. Returns excerpt text.
  • Transaction: Invokes getRecentTransactions with {"customerId": customer_id, "size": 5}. Formats lines containing date, description, and amount (must include GROCERY).
  • Eligibility: Invokes getCustomerProfile with {"customerId": customer_id}. Checks bureauScore >= 700. Formats answer stating eligibility and score (e.g., 742).
  • Tool Errors: If not result["ok"], return {"agent": agent_name, "answer": result["error"], "customerId": customer_id}.
agents/ — Policy, Transaction & Eligibility SpecialistsPYTHON
"""Three specialists. Each calls one Java MCP tool and returns {agent, answer, customerId}."""

from __future__ import annotations
from typing import Any, Callable
from mcp_tools import call_tool

ToolFn = Callable[[str, dict[str, Any]], dict[str, Any]]

ELIGIBLE_SCORE = 700


def policy(customer_id: str, prompt: str, call: ToolFn = call_tool) -> dict[str, Any]:
    result = call("searchPolicies", {"query": prompt})
    if not result["ok"]:
        return {"agent": "policy", "answer": result["error"], "customerId": customer_id}
    excerpt = (result["data"] or {}).get("excerpt", "No policy excerpt found.")
    return {"agent": "policy", "answer": excerpt, "customerId": customer_id}


def transaction(customer_id: str, prompt: str, call: ToolFn = call_tool) -> dict[str, Any]:
    result = call("getRecentTransactions", {"customerId": customer_id, "size": 5})
    if not result["ok"]:
        return {"agent": "transaction", "answer": result["error"], "customerId": customer_id}
    rows = (result["data"] or {}).get("transactions") or []
    parts = [f"{row.get('postedOn', row.get('date', '?'))} {row.get('description')} {row.get('amount')}" for row in rows]
    answer = "Recent transactions: " + "; ".join(parts)
    return {"agent": "transaction", "answer": answer, "customerId": customer_id}


def eligibility(customer_id: str, prompt: str, call: ToolFn = call_tool) -> dict[str, Any]:
    result = call("getCustomerProfile", {"customerId": customer_id})
    if not result["ok"]:
        return {"agent": "eligibility", "answer": result["error"], "customerId": customer_id}
    data = result["data"] or {}
    score = int(data.get("bureauScore") or 0)
    name = data.get("customerName") or customer_id
    if score >= ELIGIBLE_SCORE:
        answer = f"{name} is eligible for the top-up loan; bureau score {score}."
    else:
        answer = f"{name} is not eligible for the top-up loan; bureau score {score}."
    return {"agent": "eligibility", "answer": answer, "customerId": customer_id}

def freshness(self) -> Freshness:
    now = self._clock()
    age = now - self._indexed_at
    age_seconds = int(age.total_seconds())
    stale = age > self._max_staleness
    return Freshness(
        stale=stale,
        age_seconds=age_seconds,
        max_staleness_seconds=int(self._max_staleness.total_seconds()),
        indexed_at=self._indexed_at.isoformat(),
    )

Troubleshooting

Common Errors and How to Fix Them

Error You SeeRoot CauseImmediate Fix
UnsupportedOperationException: TODO Task 1 QueryGateway.handle() has not been implemented yet (throws UnsupportedOperationException). Implement Task 3 in QueryGateway.java.
HTTP 503 {"error":"orchestrator unavailable"} during query Python orchestrator is not running on port 8090. In Terminal 1, run python -m uvicorn app:app --app-dir orchestrator --port 8090.
HTTP 401 {"error":"missing token"} Request omitted the Bearer authorization header. Pass -Headers @{Authorization="Bearer lab-token"} in PowerShell.
HTTP 429 {"error":"rm limit"} More than 10 requests executed by the same RM in a 1-minute window. Wait 60 seconds for the sliding window token bucket to replenish.
KeyError: 'bureauScore' in agents.py The tool result dictionary had a None data payload. Use defensive chaining: data = result["data"] or {}, then data.get("bureauScore").
test_transaction_includes_grocery fails Transaction line formatting does not include the exact word GROCERY. Check that your string comprehension includes row.get('description').
PowerShell: The term 'uvicorn' is not recognized Python packages installed in a virtual environment not in PATH. Use python -m uvicorn ... instead of bare uvicorn ....
PowerShell: mvn test -Preference errors with redirect PowerShell treats unquoted -Preference as a redirect symbol. Always wrap in quotes: mvn test "-Preference".
